## Disk pressure notes

The session ran across multiple disk-emergency cycles
(`/private/tmp/claude-501` exhaustion). The strategy that kept
the swarm alive:

1. Removed `/tmp/ft-cc2-target/release` once (~1.4 GB).
2. Removed `/tmp/ft-cc2-target/debug/incremental` repeatedly
   (~1–22 GB per pass).
3. Removed `/tmp/ft-cc2-target/criterion` once (~3 MB but kept
   in the recipe).
4. Did **not** touch `/tmp/ft-cc2-target/debug/deps` (~26 GB
   live test binaries; deletion forces a 3-minute full rebuild).
5. Did **not** touch other agents' `/tmp/ft-*-target` dirs (16+
   active across the swarm).

Late-session deliverables intentionally favored doc + script
slices over Rust modules so the cargo cache could stabilize. The
mix of substrate Rust + scripts + docs landed as 7 closed + 8
open-with-progress beads in a single window.
