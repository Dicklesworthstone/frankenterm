# esctest-style cases
esctest/cup/clamps-to-screen CUP clamps the column to cols, not cols-1: set_cursor_pos deliberately keeps x == cols so a rewrap remembers a wrapped cursor; VT510 stops CUP at the last column.
esctest/cha/clamps-to-last-column CHA shares CUP's absolute-column clamp to cols, not cols-1 (set_cursor_pos), so the cursor lands one past the last column.
esctest/altscreen/1049-switches-to-a-blank-screen Mode 1049 also homes the cursor and resets the pen when it switches (inherited from WezTerm); xterm saves the cursor, switches and clears, leaving the position alone.
esctest/decrqss/sgr DECRQSS answers only DECSCL, DECSTBM and DECSLRM; for SGR (m) it replies 0$r (invalid) where xterm reports the current rendition.
esctest/utf8/lone-continuation-byte A lone continuation byte is dropped without a U+FFFD; vtparse feeds utf8parse, which consumes the byte that breaks a sequence instead of reprocessing it (vtparse/src/lib.rs next_utf8).
esctest/utf8/truncated-lead-keeps-the-next-byte Data loss: the ASCII byte after a truncated lead byte is swallowed (a\xc3b shows a and U+FFFD, no b); vtparse feeds utf8parse, which consumes the byte that breaks a sequence instead of reprocessing it (vtparse/src/lib.rs next_utf8).
esctest/utf8/never-valid-bytes Bytes that can never start UTF-8 (C0, C1, F5..FF) are dropped without a U+FFFD; vtparse feeds utf8parse, which consumes the byte that breaks a sequence instead of reprocessing it (vtparse/src/lib.rs next_utf8).
esctest/utf8/encoded-surrogate An encoded surrogate (ED A0 80) becomes one U+FFFD; maximal-subpart practice gives one per byte, since ED cannot be followed by A0.
esctest/utf8/overlong-form An overlong form (E0 80 AF) becomes one U+FFFD; maximal-subpart practice gives one per byte, since E0 cannot be followed by 80.
esctest/utf8/truncated-four-byte-sequence Data loss: the ASCII byte after a truncated four-byte sequence is swallowed (F0 9F 98 then b shows U+FFFD, no b); vtparse feeds utf8parse, which consumes the byte that breaks a sequence instead of reprocessing it (vtparse/src/lib.rs next_utf8).
esctest/utf8/escape-interrupts-a-sequence Visible garbage: an ESC that interrupts a UTF-8 sequence is swallowed, so CSI 1 m prints as the text [1m; vtparse feeds utf8parse, which consumes the byte that breaks a sequence instead of reprocessing it (vtparse/src/lib.rs next_utf8).
